# README media

Add the final showcase media to this folder, then replace the placeholders in the root `README.md`.

Suggested filenames:

- `singleplayer-demo.gif` - a short gas-leak response sequence
- `multiplayer-demo.gif` - two participants coordinating in one room
- `kitchen-scenario.png` - a wide view of the residential kitchen
- `fire-extinguisher.png` - safety-pin, hose, or discharge interaction
- `session-review.png` - score, action timeline, or recorded-session review

For a fast-loading GitHub page, keep GIFs short, crop them to the interaction being demonstrated, and compress large recordings before committing them.
